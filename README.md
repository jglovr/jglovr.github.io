SYSTEM UTILITIES & COMMANDS:
---------------------------
- DIR           : List files in current directory
- TYPE [file]   : Output text contents of a file (e.g. TYPE README.TXT)
- RUN [file]    : Execute program in retro window (e.g. RUN CODYFROG)
- MEM           : Display MS-DOS conventional and XMS memory allocation
- SYSINFO       : Show hardware CPU, FPU, VRAM, and BIOS summary
- TREE          : Output ASCII system directory tree structure
- COLOR [theme] : Switch screen phosphor theme (WIN95, GREEN, AMBER, C64)
- AUDIO [on/off]: Control system sound effects internally
- REBOOT        : Restart the workstation system
- SHUTDOWN      : Power off system
