# JGLOVR-OS PHYSICAL FLOPPY DISK DISTRIBUTION FOLDERS

Each directory below is a ready-to-burn physical floppy disk package formatted for 3.5" 1.44MB Floppy Disks!

FLOPPY DISK FOLDERS:
--------------------
📂 disks/CODYFROG/  -> Copy all files to Floppy Disk for Cody Frog (Mac II Edition)
📂 disks/CODY26/    -> Copy all files to Floppy Disk for Cody Frog '26 (3D Modern Edition)
📂 disks/TRAIN/     -> Copy all files to Floppy Disk for Train Game (3D Rail Sim & Covered Bridges)
📂 disks/GNOMES/    -> Copy all files to Floppy Disk for Gnomes in the Tall Grass (3D Meadow Sim)
📂 disks/SYS_VOID/  -> Copy all files to Floppy Disk for S Y S T E M _ V O I D (Vector Space Shooter)
📂 disks/GRIDMIX/   -> Copy all files to Floppy Disk for Music Grid Synthesizer (16-Step Audio Sequencer)
📂 disks/APEXCAD/   -> Copy all files to Floppy Disk for ApexCAD 3D Workstation (3D CSG CAD Engine)

HOW TO MAKE A PHYSICAL FLOPPY DISK:
-----------------------------------
1. Insert a formatted 3.5" High-Density (1.44MB) Floppy Disk into your USB Floppy Disk Drive (Drive A:\).
2. Open the folder for your desired game (e.g., `disks/TRAIN/`).
3. Copy all files inside that folder directly to `A:\`.
4. Done!

HOW TO PLAY:
------------
- ON ANY WINDOWS PC (No installation required): Double-click `RUN_GAME.BAT` on the floppy disk (`A:\`). It launches Chrome/Edge in standalone borderless kiosk mode instantly!
- ON JGLOVR DESKTOP APP / WEBSITE: Plug in the floppy drive. The workstation automatically plays floppy motor sounds, extracts embedded retro icons, installs to C:\GAMES, and launches the game automatically!
