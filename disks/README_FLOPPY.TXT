# JGLOVR-OS PHYSICAL FLOPPY DISK DISTRIBUTION PACKAGES

This directory contains standalone floppy disk executable packages formatted for physical 3.5" 1.44MB Floppy Disks!

FLOPPY DISK FILES:
------------------
- CODYFROG.EXE  (Cody Frog - Macintosh II Edition)
- CODYCLASS.EXE (Cody Frog Classic - Original 486 Edition)
- GNOMES.EXE    (Gnomes in the Tall Grass - 3D Meadow Simulation)
- SYS_VOID.EXE  (S Y S T E M _ V O I D - Vector Space Shooter)
- GRIDMIX.EXE   (Music Grid Synthesizer - 16-Step Live Sequencer)

HOW TO COPY TO PHYSICAL FLOPPY DISKS:
-------------------------------------
1. Insert a formatted 3.5" High-Density (1.44MB) Floppy Disk into a USB Floppy Disk Drive.
2. Copy any `.EXE` / `.html` file from this folder onto your physical floppy drive (e.g. `A:\CODYFROG.EXE`).
3. In JGLOVR-OS, click [ 💾 Drive A: ] or drag-and-drop the floppy file directly onto the screen.
4. JGLOVR-OS will play physical floppy motor seek audio, read the disk, and prompt:
   - "▶ RUN FROM DISK (A:\)"
   - "📥 INSTALL TO C:\GAMES" (copies the game permanently into local hard drive storage).
